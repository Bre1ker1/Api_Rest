# 🏥 API REST - Gestión de Turnos Hospitalarios

API RESTful desarrollada con **Node.js** y **Express** para la gestión de turnos médicos. Incluye persistencia en memoria (Mock Data) y una interfaz web sencilla para interactuar con la API.

---

## 🚀 Tecnologías Utilizadas

* **Backend:** Node.js, Express.js
* **Frontend:** HTML5, CSS3, JavaScript (Fetch API)
* **Pruebas:** Postman
* **Control de Versiones:** Git & GitHub
